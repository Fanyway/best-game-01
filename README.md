LUMEN DRIFT — pilot a light orb through a dark arena, collect shards to build combos, dodge patrolling sentinels, and clear all ten waves to win. A complete 2D canvas arcade game: title, HUD, waves, power-ups, pause, win and game-over screens, synthesized sound, and restart.

## Run it

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/game/ in a desktop browser.
